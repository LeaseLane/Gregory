# UX Profile

Generated by `twim-design` (`twim-craft-rules/scripts/ux-profile.py`). All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom <!-- Linear | Stripe | Apple Native | Raycast | Notion | Custom -->
- **Notes:** Composition, placement et composants suivent le twim-taste-profile de TWIM (skills/twim-taste-profile) ; les couleurs suivent le client. Mode de la surface principale : operate (voir .twim-design/surface.md). Pages marketing hors coquille d'app (Persuade / Experience) : motion nommé par le contrat de direction (`twim-impeccable` `animate`), pas les tokens 100-300 ms de `motion`. Easing Operate / Read : enter cubic-bezier(0.16,1,0.3,1), exit cubic-bezier(0.7,0,0.84,0) ; Persuade : courbes high-end (conflit 6). Glass : jamais en Operate ; en Persuade sur nav/overlays fixes seulement, avec bordure ≥ 3:1 et fallback opaque (conflit 7). Pas de bounce/spring sur le chrome Operate ; autorisé sur les surfaces Persuade avec Escape et focus fonctionnels pendant le mouvement (conflit 8). Monospace et numérotation d'index : permis quand la direction les choisit (twim-taste-profile > tasteskill, conflit 19). Lease Lane 65 / Vercel 35; marine #0C2147; Geist text, Poppins 600 titles and figures; radii 8/6/3; dense; see design/decisions.md

## Banned anti-aesthetics

- Glassmorphism / backdrop-filter sans bordure à contraste ≥ 3:1 (Operate : interdit ; Persuade : éléments fixes seulement)
- Pills pastel flottantes sur des métadonnées ordinaires (horodatage, auteur, taille)
- Gradients décoratifs arbitraires et bordures néon
- Gradients radiaux arc-en-ciel sur des CTA standards
- Illustrations cartoon d'état vide (personnages qui saluent)
- Barres de défilement imbriquées et icônes dans les champs
- Texte sous 12 px, y compris les eyebrows (12 px + letter-spacing)
- Sections à espacement surdimensionné (py-24+) : padding de section 64-112 px desktop, 40-64 px mobile (« bien cadré »)
- Emoji comme icônes d'interface ; plus d'une bibliothèque d'icônes
- uppercase eyebrow labels

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `audit-protocol`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
